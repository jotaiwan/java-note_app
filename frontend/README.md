# Note App — Frontend

React frontend for the Note App project.

- **Backend:** Java 21 · Spring Boot 3.2 (port 5099)
- **Frontend:** React · npm (port 5000 via nginx)

## Quick Start

```bash
# From project root — starts both backend + frontend:
./lup.sh

# Frontend only:
cd frontend && npm install && npm start
```
